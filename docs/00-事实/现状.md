## 代码结构

### 入口

| 文件 | 干什么 |
|---|---|
| `main.py` | `main()` 启动：校验菜谱 → 建库 → 加载场景 → 起天气/提炼两个后台循环 → 起通道。`handle()` 处理一条消息，**拆成四步**：`_make_turn`（纯构造，出错就崩）→ `_touch_person`（认人，失败不挡回复）→ `_think`（跑前置链，失败回兜底话术）→ `_record`（记账，失败不挡回复） |
| `cli.py` | `status` / `doctor` / `last` + 4 个占位（think/memory/dsh/apply） |

### 场景（5 个，每个 = scene.py + recipe.yml）

| 场景 | 干什么 |
|---|---|
| `chat.reply` | 纯文字出话，菜谱 18 个块 |
| `chat.image` | 带图出话，多一个图片指令块 |
| `chat.qa` | 查证：调工具 → 要求模型输出结构化 JSON → 解析成 facts → 写库 |
| `label` | 消息标注，4 秒软截止，超时降级 `uncertain` |
| `memory.extract` | 记忆提炼，输入一批对话，输出 JSON 数组 |

`scenes/tick/` 只有菜谱、没有 `scene.py`——注册表自动跳过。

| 文件 | 干什么 |
|---|---|

## 一条消息的完整流程

```
通道读一行 → Incoming
  ↓
_make_turn        生成 turn_id、组 Turn（纯构造，出错就崩）
  ↓
_touch_person     建/更新 people 档案（失败不挡）
  ↓
_think → chain.run
  ├ quick_judge   规则抢答（"哈哈"→不查，"天气"→查），命中就不问模型
  ├ label 场景    没抢到才问模型，4 秒软截止，超时→uncertain
  ├ 要查证 → chat.qa
  │    工具循环（weather/web_search/web_fetch）
  │    模型输出结构化 JSON → 解析成 facts → 写 4-facts → 交给 reply
  └ 出话 → chat.reply / chat.image
        assemble：system 块 + 历史多轮 + 当前 user
        历史展开成 user/assistant 轮次，群聊带发言人名字
        工具循环 → 模型 → 回复
  ↓
_record
  ├ turns.jsonl（一轮一行：谁说的、哪条链、标签、拼了哪些块、投递状态）
  ├ runs.jsonl（每次调用：完整 prompt、输出、usage）
  ├ tools.jsonl（每次工具调用）
  └ organize.from_turn → interactions（他一句、她一句、她的动作）
  ↓
通道打印
```

**后台**：03:00 提炼记忆，07:00 预取天气。

## 关键机制（容易忘的）

| 机制 | 规则 |
|---|---|
| **历史与记忆错开** | 历史管最近 3 天（当前会话）；记忆**跳过最近 3 天**（那些历史里有）；主动记的（`manual*`）例外 |
| **记忆带日期** | 拼进 prompt 时每条是 `[2026-10-01] 浅华不吃辣` |
| **动作块** | 上一轮她调过什么工具，拼成一块"这是真的执行记录"——否则她会把自己的真实行为当成编造 |
| **三层工具过滤** | 菜谱说用哪个箱 → `persona.yml` 的 `allow` 白名单 → 全量箱不受 allow 限制 |
| **工具结果三件事** | 带来源、带时间、失败分类型（连不上 / 没找到 / 名字不对） |
| **提炼每天一次** | 03:00，启动补跑，分批 60 轮，整批一个事务 |
| **天气预取** | 07:00，三城 × 两天，写事实库，保质期到当天 23:59 |
| **失败隔离** | 前置链失败回兜底话术；记账失败照常回话；两者都写 events，`cli status` 能看 |

## 已知问题

1. **她会重复调工具**（问天气调 2 次、记忆搜 3 次）——按浅华的意思先不治。
2. **`label` 是 4 秒软截止**，不是最初设计的 3 秒（真模型 0.9 秒，留了余量）。
3. **`ask_dsh` / `qq_do` 没实现**，但 `persona.yml` 的 allow 里写了；`cli status` 会提示。
4. **`tick/` 只有菜谱**，没有 `scene.py`。
5. **单字查询搜不到**（关键词切 2–3 字片段），靠向量兜着。
6. **`products/` 和 `labels` 只写不读**，留着是为了调试。
