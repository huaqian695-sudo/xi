1. **`tools.jsonl` 是空的**。M0 没有真工具，账本开了但没账。这是预期的，不是 bug。
2. **只写了两个场景**。`tick` 有菜谱、没有 `scene.py`，注册表会跳过它——这正是"加场景只加一个文件夹"的证明：缺一半也不会炸。

4. **`prompt` 全文还没进 `runs.jsonl`**。现在只记了字数。M1 补。

## 一件值得注意的事

prompt 实际拼出来 **2580 字**，其中人设（self + chat + thinking）占了 1900 字左右，占 74%。
这正是我提醒过的"人设越长，留给记忆和历史的空间越少"——现在记忆和历史还是占位符，
等 M2 接上，总量会明显上升。到时候如果觉得她被稀释了，最容易调的是把 `thinking.md` 从
出话里拿掉，只在心跳拼。
